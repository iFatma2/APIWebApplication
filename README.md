# Simple Web API Project 🚀

This is a simple project I built using **ASP.NET Core** and **JetBrains Rider** to practice and understand how APIs and Controllers work.

## What I did in this project:
I created a basic API that contains **two main controllers**:
1. **BooksController**: To manage book data.
2. **AuthorsController**: To manage author information.

## Methods Implemented:
In each controller, I added 3 basic methods to understand the flow of data:
* **GET**: To fetch and display data.
* **POST**: To simulate adding new records.
* **DELETE**: To simulate removing data using an ID.

## Tools Used:
* **IDE**: JetBrains Rider.
* **Framework**: .NET 8/9 (ASP.NET Core).
* **Documentation**: Swagger UI (Swashbuckle) to test the endpoints easily.

This project was a great way to get hands-on experience with routing, HTTP methods, and API structure.
